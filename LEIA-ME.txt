# CRÔNICAS — Portal RPG 2.0

## Abrir
Extraia o ZIP e abra `index.html` em um navegador moderno.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz.
3. Abra Settings → Pages.
4. Selecione Deploy from a branch, branch `main` e pasta `/ (root)`.

## Salvamento local
As fichas e anotações são salvas automaticamente no localStorage do navegador. Não é necessário login. Os dados não sincronizam automaticamente entre dispositivos; faça backups JSON.

## Compartilhamento
- Na ficha, use Exportar JSON para baixar uma ficha individual.
- Use Criar link para copiar um link contendo os dados da ficha. Ao abrir, o destinatário poderá importá-la no navegador dele.
- Links podem ficar longos quando a ficha contém uma imagem grande. Nesse caso, prefira JSON.

## Painel do mestre
O painel é local e sem login. Ele mostra as fichas presentes no navegador do mestre e permite importar fichas JSON recebidas. Ele não consegue visualizar automaticamente o localStorage dos jogadores em outros dispositivos.

## Retratos
As imagens são guardadas no navegador e incluídas nos backups JSON. Use imagens de até 2 MB para evitar fichas muito grandes.
